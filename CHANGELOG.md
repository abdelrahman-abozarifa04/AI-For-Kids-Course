# Changelog

## 1.0.0 (2026-11-25)

First complete release.

- **Kids track (6–9):** 8 unplugged lesson plans, teacher guide, 74 printable cards in 7 decks, card generator (`tools/build_cards.py`, HTML + PDF).
- **Teens track (15–18):** 4 terms / 16 units of lesson notes, teacher guide, 12 Colab notebooks with exercises and tested solutions, including Egyptian-Arabic NLP.
- **Final project kit:** Streamlit starter app, proposal template, rubric.
- **Infrastructure:** MkDocs website (RTL), CI running every notebook and every solution, issue templates for classroom reports.
- Licensing: code MIT, content CC BY 4.0.

## 0.1.0 (2025)

Initial two-year syllabus outline for ages 15–18.
