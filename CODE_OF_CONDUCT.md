# Code of Conduct

This project is used by teachers and learners, including children. We expect every contributor to be respectful, patient, and kind.

## Our standards

- Be welcoming to newcomers and to people contributing in Arabic or English.
- Give constructive, specific feedback on content and code — never on people.
- Keep all content age-appropriate. Nothing violent, sexual, or frightening in kids' material.
- Never share personal data or photos of students in issues, PRs, or examples.

## Unacceptable behavior

Harassment, insults, discriminatory jokes, trolling, or publishing others' private information.

## Enforcement

Report problems to the maintainer by opening a private security advisory on GitHub or by contacting the maintainer through their GitHub profile. The maintainer may remove content and block contributors who violate this code.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
