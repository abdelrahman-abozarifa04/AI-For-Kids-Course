## ليه المشروع ده؟

- **بالعربي:** معظم محتوى تعليم الذكاء الاصطناعي للأطفال بالإنجليزي. هنا الحصص بالعربي، والأمثلة من حياتنا (كشري، أسعار شقق بالجنيه، عامية مصرية).
- **من غير أجهزة للصغيرين:** مسار الأطفال كله "unplugged"، يعني ينفع في أي فصل.
- **مجرّب:** كل notebook وكل حل تمرين بيتشغل أوتوماتيك مع كل تعديل (CI)، فمفيش كود بايظ.
- **مفتوح:** الكود MIT والمحتوى CC BY 4.0. انسخ، اطبع، ترجم، درّس، حتى في كورسات بفلوس.

## هتلاقي إيه

| | الأطفال (٦–٩) | الشباب (١٥–١٨) |
|---|---|---|
| المدة | ٨ حصص × ٦٠ دقيقة | ٤ تيرمات × ١٢ أسبوع |
| الأجهزة | ولا حاجة | لابتوب + إنترنت (Colab) |
| المحتوى | خطط حصص + ٧٤ كارت للطباعة | ١٦ وحدة + ١٢ notebook |
| المشاريع | حفلة تخرج + "اختراعي الذكي" | شات بوت ← موديل صور ← مساعد ← تطبيق ويب |
