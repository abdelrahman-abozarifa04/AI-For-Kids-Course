# التيرم ٤: الابتكار والمشروع النهائي

**الهدف:** نستخدم كل اللي اتعلمناه علشان نبني **منتج AI حقيقي يحل مشكلة**، ونعرضه.
**المشروع:** تطبيق ويب بالذكاء الاصطناعي، في فرق من ٢–٤.

🧰 **عدة المشروع:** [`projects/final-project-starter`](https://github.com/abdelrahman-abozarifa04/ai-for-kids-course/tree/main/projects/final-project-starter): تطبيق Streamlit جاهز تبدأ منه، ونموذج المقترح، وجدول التقييم.

---

## الوحدة ١: الذكاء الاصطناعي في البيزنس والشركات الناشئة

### الأهداف
- يشرح إزاي الشركات بتعمل فلوس من AI.
- يحوّل مشكلة لفكرة منتج باستخدام **Lean Canvas** مبسّط.

### الأفكار الأساسية
- الـ AI لوحده مش منتج. المنتج = **مشكلة حقيقية + ناس بتعاني منها + حل أحسن من الموجود**.
- أشهر طرق الاستخدام: توقع الطلب، توصيات، خدمة عملاء (شات بوت)، كشف احتيال، أتمتة شغل متكرر.
- **أسئلة لازم تتسأل:** البيانات هتجيبها منين؟ لو الموديل غلط، إيه اللي هيحصل؟ ليه حد هيدفع؟

### نشاط: "Lean Canvas في ٢٠ دقيقة"

| الخانة | السؤال |
|---|---|
| المشكلة | إيه أكبر ٣ مشاكل؟ |
| مين | مين بيعاني؟ (حدد بالظبط: "طلاب تالتة ثانوي في الأقاليم") |
| الحل | بالـ AI هتعمل إيه؟ |
| البيانات | الموديل هيتعلم من إيه؟ |
| الميزة | ليه أحسن من الموجود؟ |
| المقياس | هتعرف إنه نجح إزاي؟ |

## الوحدة ٢: AI للخير

### الأهداف
- يتعرف على مشاريع AI بتخدم المجتمع.
- يربط مشروعه بهدف من **أهداف التنمية المستدامة (SDGs)**.

### أمثلة ومجالات
- **المناخ والزراعة:** توقع الطقس، وري ذكي يوفّر مية، وكشف أمراض النبات من صورة (مهم جداً في مصر).
- **الصحة:** فحص صور الأشعة، وتذكير المرضى بالأدوية.
- **ذوي الهمم:** تحويل الكلام لنص للصم، ووصف الصور للمكفوفين، ولغة الإشارة.
- **الكوارث:** تحليل صور الأقمار الصناعية بعد الزلازل والفيضانات.
- **التعليم:** محتوى بالعربي للأطفال، زي المشروع ده!

### نشاط: "خريطة المشاكل" (٣٠ دقيقة)
كل طالب يكتب ٣ مشاكل في مدرسته أو حيّه أو مدينته على sticky notes. لزقوها على الحيطة، وجمّعوها، وصوّتوا. أكتر ٥ مشاكل تبقى مرشحة للمشروع النهائي.

## الوحدة ٣: تخطيط المشروع النهائي

### الأهداف
- يكتب مقترح مشروع واضح.
- يقسّم الشغل على الفريق ويعمل خطة زمنية.
- يستخدم GitHub علشان يشتغل مع فريقه.

### المقترح (صفحة واحدة)
استخدم [`PROPOSAL_TEMPLATE.md`](https://github.com/abdelrahman-abozarifa04/ai-for-kids-course/blob/main/projects/final-project-starter/PROPOSAL_TEMPLATE.md). لازم يتوافق عليه من المدرس قبل البداية.

### أدوار الفريق

| الدور | المسؤولية |
|---|---|
| 📊 مسؤول البيانات | يجمع وينضّف البيانات |
| 🧠 مسؤول الموديل | يدرّب ويقيّم |
| 🖥️ مسؤول الواجهة | تطبيق Streamlit |
| 🎤 مسؤول العرض | العرض والتوثيق، وبيتأكد إن كل حاجة مكتوبة |

(في فريق من ٢، كل واحد ياخد دورين.)

### GitHub في ٤ خطوات
1. واحد يعمل repo، ويضيف الباقيين **collaborators**.
2. كل واحد يشتغل على **branch** باسمه.
3. يفتح **Pull Request** وزميله يراجعه.
4. **Merge** بعد الموافقة.

### خطة الـ ٦ أسابيع
| الأسبوع | الهدف |
|---|---|
| ١ | المقترح + جمع البيانات |
| ٢ | تنضيف البيانات + أول موديل (حتى لو وحش) |
| ٣ | تحسين الموديل + قياس |
| ٤ | الواجهة (Streamlit) |
| ٥ | اختبار مع مستخدمين حقيقيين + تصليح |
| ٦ | العرض النهائي |

## الوحدة ٤: التطوير والعرض

### الأهداف
- يبني تطبيق ويب للموديل بـ **Streamlit**.
- يختبر المنتج مع ٣ مستخدمين على الأقل.
- يقدّم عرض ٥ دقايق مقنع.

### من notebook لتطبيق
```bash
cd projects/final-project-starter
pip install -r requirements.txt
streamlit run app.py
```
وللنشر مجاناً: ارفع الـ repo على GitHub، وادخل على [share.streamlit.io](https://share.streamlit.io) واختاره.

### هيكل العرض (٥ دقايق)
1. **المشكلة** (٣٠ ثانية): قصة شخص حقيقي.
2. **الحل** (٣٠ ثانية): في جملة واحدة.
3. **Demo حي** (٢ دقيقة): وريهم بيشتغل.
4. **إزاي بيشتغل** (١ دقيقة): البيانات، الموديل، الدقة.
5. **الحدود والأخلاقيات** (٣٠ ثانية): بيغلط فين؟ مين ممكن يتضرر؟
6. **الخطوة الجاية** (٣٠ ثانية).

### مسابقات تقدروا تشاركوا فيها
اسألوا المدرس عن المسابقات المتاحة السنة دي: أولمبياد الذكاء الاصطناعي، و[Kaggle](https://www.kaggle.com) (فيه مسابقات للمبتدئين)، وهاكاثونات الجامعات المصرية.
