# دليل المدرس: مسار الشباب

## الجدول المقترح

- **التيرم:** ١٢ أسبوع، حصة واحدة في الأسبوع (٩٠–١٢٠ دقيقة).
- **كل وحدة:** حوالي ٢–٣ أسابيع. آخر أسبوعين في كل تيرم للمشروع.

| الأسبوع | المحتوى |
|---|---|
| ١–٢ | الوحدة ١ |
| ٣–٥ | الوحدة ٢ |
| ٦–٨ | الوحدة ٣ |
| ٩–١٠ | الوحدة ٤ |
| ١١–١٢ | المشروع + العرض |

## شكل الحصة (١٠٠ دقيقة)

| الجزء | الوقت |
|---|---|
| مراجعة + سؤال تحفيزي | ١٠ د |
| شرح الفكرة (من غير كود) | ٢٠ د |
| Notebook مع بعض (المدرس بيشغّل والطلاب ورا) | ٣٠ د |
| تمارين في مجموعات من ٢ (pair programming) | ٣٠ د |
| نقاش + واجب | ١٠ د |

## التجهيز

- كل طالب محتاج **حساب Google** علشان Colab. لو الطلاب تحت ١٨، اتأكد من سياسة المدرسة.
- **من غير إنترنت؟** سطّب Python و `pip install -r requirements.txt` وشغّل الـ notebooks بـ Jupyter.
- اعمل نسخة من الـ notebook لكل طالب (`File → Save a copy in Drive`) علشان يحفظ شغله.

## التمارين والحلول

- كل تمرين عليه **🏋️**، وتحته الحل مقفول في **"الحل"**.
- شجّع الطلاب يحاولوا ١٠ دقايق على الأقل قبل ما يفتحوا الحل.
- كل الحلول **متجرّبة أوتوماتيك** في الـ CI مع كل تعديل على المشروع، فهي شغالة.

## التقييم

| العنصر | الوزن |
|---|---|
| التمارين الأسبوعية | ٣٠٪ |
| مشروع التيرم | ٥٠٪ |
| المشاركة والنقاش | ٢٠٪ |

كل مشروع ليه **جدول تقييم (rubric)** في آخر الـ notebook أو صفحة التيرم.

## الذكاء الاصطناعي في الفصل: سياسة مقترحة

الطلاب هيستخدموا ChatGPT وClaude وغيرهم. بدل المنع، علّمهم الاستخدام الصح:

1. ✅ مسموح: يشرحلك خطأ، يديك فكرة، يراجع كودك.
2. ❌ مش مسموح: يكتب المشروع كله وتسلّمه باسمك.
3. 📝 اكتب في المشروع: "استخدمت AI في كذا".
4. 🧠 لازم تقدر تشرح كل سطر في كودك. المدرس ممكن يسأل.
