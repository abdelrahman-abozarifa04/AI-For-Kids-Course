# الحصة ٨: الذكاء الاصطناعي وإحنا + حفلة التخرج 🎓

**الفكرة:** الذكاء الاصطناعي أداة قوية. **إحنا** اللي بنقرر نستخدمها إزاي: بأمان وبأمانة وبعدل.
**الكروت:** `scenarios` (٨ كروت) · **كلمة الحصة:** مسؤولية

## الأهداف

- الطفل يعرف ٣ قواعد لاستخدام الذكاء الاصطناعي بأمان.
- الطفل يراجع كل كلمات المسار ويشرح واحدة منها.
- حفلة تخرج بسيطة وشهادات.

## المواد

- كروت `scenarios`.
- كارتين لكل طفل: 🟢 **تمام** و 🔴 **استنى!**
- شهادات تخرج (اختياري). اكتب اسم الطفل بخط إيدك.

## إحماء (١٠ دقايق): "حيطة الكلمات"

اشاور على كل كلمة على الحيطة (ذكاء اصطناعي، خوارزمية، نمط، تصنيف، تعلّم، بيانات، قرار)، وطفل يشرحها **بمثال**.

## النشاط الرئيسي (٣٠ دقيقة)

### الجزء أ: "تمام ولا استنى؟" (٢٠ دقيقة)

1. اقرا كارت موقف بصوت عالي.
2. كل طفل يرفع 🟢 أو 🔴.
3. اسأل طفلين برأيين مختلفين: "ليه؟"
4. اقرا التلميح اللي على الكارت ولخّصوا القاعدة.

القواعد اللي هتطلع من الكروت:

| القاعدة | الكروت |
|---|---|
| 🔒 **أسراري ليا:** الاسم الكامل والعنوان والصور بنسأل فيها الكبار الأول | 📸 🏠 |
| 🤔 **الذكاء الاصطناعي بيغلط:** نتأكد دايماً | 🤖 🍏 |
| 🙋 **أكون أمين:** أقول لو الكمبيوتر ساعدني | 🎨 📚 |
| ⚖️ **العدل:** لو حاجة مش عادلة نقول للكبار | 🧑‍🤝‍🧑 |
| 🌍 **نستخدمه للخير** | 🌍 |

### الجزء ب: "اختراعي الذكي" (١٠ دقايق)

كل طفل يرسم **روبوت أو تطبيق ذكي يساعد حد**: جدته، مدرسته، شارعهم، الحيوانات. ويكتب أو يقول جملة: "بيتعلم من ... علشان يساعد ...".

## حفلة التخرج (٢٠ دقيقة بدل النقاش والختام)

1. معرض صغير: الرسومات على الحيطة، والأهالي أو الفصل التاني يزوروا.
2. كل طفل يقدّم اختراعه في ٣٠ ثانية.
3. تسليم الشهادات: "**مستكشف ذكاء اصطناعي** 🎓".
4. صورة جماعية (**بموافقة الأهالي بس**).
